# Insurance release readiness

Do not enable insurance flags merely because the Sprint I1 code is deployed.
Before any production enablement, complete legal and compliance approval of the
operating model, configure real operating-model data through approved controls,
confirm private object storage and malware scanning, review document retention,
validate access monitoring, and complete a security review.

The seed uses `example.test` values and draft records. It is not regulatory
data, is not a licence assertion, and must not be promoted to production.
