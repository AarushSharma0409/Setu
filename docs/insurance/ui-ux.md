# Insurance UI and UX

Insurance uses Setu's existing neutral surfaces, restrained violet accent, generous spacing, and factual language. The public path is: understand needs, request available quotes, compare, then continue with an insurer.

The customer dashboard separates active assessment progress, quote availability, and saved quotes. The assessment is section-based with visible progress, server-confirmed save feedback, native semantic controls, local field errors, review, disclosures, and separately labelled consent.

Quote request and detail pages distinguish an available quote from insurer approval. Comparison and handoff controls remain private, feature-gated, and do not make savings or policy-issuance claims.
